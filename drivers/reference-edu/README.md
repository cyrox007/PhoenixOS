# Эталонный драйвер QEMU EDU

Этот каталог содержит небольшой независимый драйвер на Rust `no_std` для **виртуального** учебного PCI-устройства QEMU `1234:11e8`.

Пример предназначен для переноса архитектурных приёмов в будущие драйверы PhoenixOS, а не для установки на настоящие PCI-устройства.

## Состав

- `src/lib.rs` — декларация `DriverDescriptor`, регистрация в общем `DriverRegistry`, точный выбор устройства, проверка адресного диапазона DMA и доставка причин прерываний через атомарный `InterruptMailbox`.
- `kernel/src/reference_edu.rs` — связующий код ядра, который на QEMU действительно отображает MMIO, настраивает MSI, использует `DmaBuffer` с системным распределителем и подтверждает двусторонний обмен 256 байт.
- `docs/reference-driver-edu.md` — [подробное русскоязычное руководство](../../docs/reference-driver-edu.md).

## Как проверить

После установки предусмотренного в репозитории инструментария Rust:

```sh
cargo test -p phoenix-reference-edu
```

Полная проверка ядра выполняется обычным рабочим процессом GitHub Actions на QEMU + OVMF, где в команду запуска добавлено `-device edu,id=phoenix-edu`. Успех требует настоящих MSI-событий `0x42` и `0x100`, проверки 256 байт и возврата 1/1 страниц DMA.

**Ограничения:** учебный QEMU, один процессор, адресная маска EDU 28 бит, прямое DMA без IOMMU. Полноценного многопроцессорного распределителя MSI-X и физического аппаратного испытания здесь нет.
