# Драйверы

Общий реестр драйверов уже реализован в `crates/driver-registry`. Он отвечает за регистрацию, проверку версии интерфейса, сопоставление PCIe-устройств, детерминированный выбор реализации и запуск выбранного драйвера без динамического выделения памяти.

Конкретные аппаратные драйверы размещаются здесь по мере реализации этапа 0.3.

Подробности: `docs/drivers.md`.
