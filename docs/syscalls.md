# ABI системных вызовов

Этап 0.1 начинает вход в системные вызовы с отдельного языка-независимого контракта. Аппаратный переход `SYSCALL/SYSRET` будет подключён следующим инкрементом, но его регистровая граница уже не должна зависеть от внутренних типов Rust.

## Версия

Текущий экспериментальный ABI имеет версию `0`. Номера конкретных системных вызовов ещё не объявлены стабильными. После перехода публичных интерфейсов из экспериментального состояния несовместимые изменения потребуют новой версии ABI.

## x86-64: вход

При выполнении системного вызова регистры интерпретируются так:

- `RAX` — номер системного вызова;
- `RDI` — аргумент 0;
- `RSI` — аргумент 1;
- `RDX` — аргумент 2;
- `R10` — аргумент 3;
- `R8` — аргумент 4;
- `R9` — аргумент 5.

`RCX` и `R11` не используются для аргументов, потому что механизм x86-64 `SYSCALL/SYSRET` использует их для адреса возврата и флагов.

## x86-64: результат

Возврат использует два регистра:

- `RAX` — 64-битное значение результата;
- `RDX` — статус.

Статус `0` означает успех. Ненулевое значение — код ошибки. Отдельный статус сохраняет полное 64-битное пространство значения и не требует резервировать отрицательный диапазон.

## Представление

Crate `phoenix-syscall-abi` работает без стандартной библиотеки и определяет `#[repr(C)]` структуры `SyscallRequest` и `SyscallReturn`, а также прозрачный статус. Эти типы служат эталонным описанием контракта и тестируются независимо от ядра.

## Настройка аппаратного пути

Ядро проверяет расширенный CPUID-бит `SYSCALL/SYSRET`. При наличии поддержки настраиваются:

- `IA32_STAR` — селектор кода ядра для входа;
- `IA32_LSTAR` — адрес точки входа;
- `IA32_FMASK` — маска, очищающая TF, IF и DF на входе;
- `IA32_EFER.SCE` — разрешение механизма системных вызовов.

После записи все MSR читаются обратно и проверяются. Пока `LSTAR` указывает на защитный stub с `ud2`: реальный `SYSCALL` ещё не выполняется. QEMU подтверждает шаг маркером `syscall msr self-test: OK`.

## Следующий инкремент

Следующий шаг — заменить защитный LSTAR stub минимальным assembly entry path, сохранить RCX/R11 и аргументы ABI, вызвать Rust-диспетчер и безопасно вернуться в контролируемую точку без перехода в ring 3. После этого будет добавлен настоящий ring3-переход и `SYSRET`.
