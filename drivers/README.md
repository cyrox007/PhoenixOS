# Драйверы PhoenixOS

В `crates/driver-registry` расположен общий реестр драйверов. Он проверяет версию интерфейса, сопоставляет PCIe-устройства по точным идентификаторам, детерминированно выбирает реализацию и запускает обработчик с явными ресурсами без скрытых выделений памяти.

## Эталонный драйвер

**`drivers/reference-edu/`** — минимальная самостоятельная библиотека `no_std` с примером регистрации, ограничений DMA и обработки прерываний. Её проверочный адаптер `kernel/src/reference_edu.rs` действительно работает с виртуальным устройством QEMU EDU `1234:11e8`: проверяет регистры, передаёт 256 байт в обе стороны по DMA, обрабатывает MSI и возвращает выделенную физическую страницу.

- [Полное руководство и последовательность разработки](../docs/reference-driver-edu.md)
- [Основы реестра и жизненного цикла](../docs/drivers.md)
- [Общий интерфейс DMA](../docs/dma.md)

Эталонный драйвер не должен запускаться на физическом ноутбуке. Поддержка внешних драйверов, полноценного механизма назначения MSI-X и аппаратного IOMMU остаётся отдельными задачами.
