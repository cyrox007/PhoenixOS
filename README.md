# PhoenixOS

PhoenixOS is an experimental, from-scratch operating system project targeting modern x86-64 PCs.

Development happens on `develop`; `main` is reserved for stable integration points. The initial platform target is x86-64 + UEFI, with QEMU/OVMF as the reference environment and a deliberately small supported-hardware matrix for early releases.

The project is being designed as a complete platform rather than only a kernel: kernel, drivers, userspace, desktop, SDK, porting documentation, system applications, and a small set of games are all part of the roadmap.

> Status: project bootstrap in progress.
