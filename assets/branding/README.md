# Фирменные ресурсы PhoenixOS

Эта папка хранит выбранное направление фирменного стиля PhoenixOS.

Текущие файлы считаются **рабочими векторными ресурсами**, а не окончательно замороженным товарным знаком. Их можно использовать в прототипах, загрузочном экране, интерфейсе, документации и презентационных материалах. К финальной полировке знака, шрифта и пропорций вернёмся отдельно.

## Файлы

- `logo-primary.svg` — основной цветной знак PhoenixOS. Предпочтительный вариант для сайта, документации, презентаций и крупных экранов.
- `logo-monochrome.svg` — одноцветная версия. Использовать там, где цвет и свечение недоступны или нежелательны.
- `system-icon.svg` — компактная версия знака для значка системы, меню загрузки, настроек и других небольших поверхностей.
- `boot-screen.svg` — базовая композиция загрузочного экрана.
- `wallpaper-concept.svg` — рабочая концепция фонового изображения рабочего стола.

## Визуальное направление

Основная идея — не буквальная иллюстрация птицы, а абстрактный феникс будущего: движение вверх, восстановление, энергия и развитие. Форма собирается из плавных лент и дуг, чтобы знак оставался узнаваемым даже при упрощении.

Базовая палитра:

- тёмный фон: `#070B12`;
- холодный синий: `#2EA8FF`;
- яркий оранжевый: `#FF7A18`;
- золотой свет: `#FFC14D`;
- холодный металл: `#DCE7F2`.

Оранжевый и синий должны работать как два энергетических полюса, а не как декоративная радуга. В интерфейсе их следует использовать умеренно.

## Правила использования

1. Не растягивать знак непропорционально.
2. Не добавлять новые контуры, тени и внешние эффекты поверх мастер-файлов без отдельного решения.
3. Для размеров меньше 32 пикселей использовать `system-icon.svg`, а не полный основной знак.
4. Монохромная версия должна оставаться читаемой без градиентов.
5. В загрузочном экране предпочтителен минимальный знак без лишней информации.
6. Финальный логотип позднее должен получить отдельные экспортные варианты PNG/WebP/ICO и проверку на светлом/тёмном фоне.

## Статус

Направление утверждено как рабочее. Детальная доработка формы, типографики PhoenixOS и окончательных экспортов отложена до следующего прохода по фирменному стилю.
