## Ближайшая задача

### 1. Интерфейс DMA с заделом на IOMMU

Цель — дать драйверам единый безопасный способ получать память для обмена с устройствами, не связывая конкретный драйвер с текущей схемой физической памяти.

Критерии готовности:

- [x] отдельный `no_std`-интерфейс DMA;
- [x] явное различение процессорского виртуального адреса и адреса, видимого устройству;
- [x] проверяемые размеры, выравнивание и границы;
- [ ] поддержка согласованного выделения/освобождения буфера без скрытой кучи на критическом пути;
- [ ] возможность позднее подставить преобразование адресов IOMMU без изменения интерфейсов драйверов;
- [x] программная интеграционная проверка с текущим реестром драйверов (фиктивное устройство, без аппаратного DMA);
- [x] модульные проверки ошибочных размеров, переполнений и повторного освобождения;
- [x] обновление `STATUS.md` и `ROADMAP.md`.

**Дополнительные завершённые меры безопасности:**

- [x] при отказе освобождения DMA-области сохраняются владение, действующий идентификатор и возможность повторной попытки; добавлена проверка отказа и восстановления.

- [x] выделен отдельный обратимый программный контракт отображения физических адресов в адреса устройства; при ошибке снятия сохраняется действующее отображение, проверены повторная попытка и двойное снятие.

- [x] программная связка физических страниц, отображений процессора и устройства: прекращение доступа и последовательное освобождение, с испытаниями на системном распределителе и имитации отображений (без аппаратного DMA).

- [x] отображение выделенных физических страниц в зарезервированное окно ядра через существующий `ActivePageTable`: учёт частичного результата и восстановление после ошибок, с проверками на имитации таблиц страниц. Применение на физическом устройстве ещё не разрешено.

- [x] отдельный реестр непересекающихся виртуальных и физических DMA-окон фиксированной вместимости, защита от устаревших идентификаторов, запрет освобождения отображённых окон; флаги кэширования выбираются явно. Аппаратное подтверждение PAT/MTRR остаётся отдельной работой.

**Промежуточный итог:** выполнено 6 из 8 критериев интерфейса DMA. Не закрыты полное аппаратно согласованное выделение/освобождение и подтверждение сменяемого отображения через IOMMU. Реестр владения отслеживает активность, физический распределитель выдаёт непрерывные страницы с ограничением адресов, но полной связки с аппаратурой пока нет.

- [ ] пример DMA;
- [ ] пример прерываний;

### 7. Зачистка устаревших рабочих путей

- [ ] убрать рабочую зависимость от xAPIC там, где выбран x2APIC;
- [ ] не использовать PIC 8259 как рабочий контроллер;
- [ ] не добавлять BIOS/CSM;
- [ ] не добавлять IDE/PATA и старые USB-контроллеры;
- [ ] оставить только безопасное отключение наследуемых блоков, если это требуется современной платформой.

## Правило выполнения

Каждая задача выполняется отдельной небольшой веткой. До слияния обязательны профильные тесты, затем полная автоматическая проверка. Если изменение меняет фактическую границу этапа, одновременно обновляются `TASKS.md`, `ROADMAP.md` и `STATUS.md`.
