# Пользовательское пространство

Пользовательское пространство PhoenixOS уже имеет минимальный исполняемый контур: отдельное адресное пространство, загрузку ELF64, передачу аргументов и окружения через стабильный ABI, системные вызовы и библиотеку phoenix-user-runtime.

Каталог smoke содержит минимальную реально компилируемую пользовательскую программу. Она собирается отдельно для x86_64-unknown-none, встраивается в проверочный образ ядра, загружается штатным ELF-загрузчиком, запускается в пользовательском режиме и завершает процесс через системный вызов. Это эталон минимального исполняемого файла до появления оболочки и обычных системных программ.


## Чтение событий клавиатуры и мыши

В пользовательскую библиотеку добавлен `input_read`: один вызов возвращает одну 48-байтовую запись ввода. При отсутствии событий возвращается `EAGAIN`, без разрешения — `EACCES`; указатель и размер буфера дополнительно проверяет ядро. Для чтения процессу при запуске должна быть выдана возможность устройства ввода с правом чтения.

Программа `userspace/input-probe` проверяет настоящий обмен с USB-клавиатурой через xHCI в QEMU. Штатная оболочка `phxsh -c input` читает одну запись, форматирует событие клавиатуры, мыши или изменения устройства с номером последовательности и счётчиком потерь. Действительная возможность может быть передана доверенным запускающим процессом через переменную окружения `PHOENIX_INPUT_CAP` в виде 16 шестнадцатеричных знаков; одно имя переменной не предоставляет доступа без полномочий в ядре.

Эти два пользовательских ELF-процесса последовательно получили пять событий из общей очереди в QEMU. Планировщик ядра уже обслуживает xHCI собственным потоком в QEMU и безопасно останавливает его по запросу. Полноценная длительная интерактивная работа оболочки с непрерывным пользовательским вводом остаётся отдельной задачей.
